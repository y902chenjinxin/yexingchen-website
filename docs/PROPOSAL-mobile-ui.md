# 移动端质感改版方案 ·「宣纸手账」

> 2026-10-10 · 状态：**已拍板，P0~P3 一步到位（夜星 2026-10-10）**
> 参考来源：夜星提供的 5 张截图（Neo-Brutalism + 手账/杂志编辑风）+ GitHub 调研
> 参考库：DMaven Warm Fusion（骨=新粗野主义/皮=瑞士暖白，与本方案最接近）、NeoBrutal-Kit、@mariojgt/neo-css

## 一、质感公式（从截图提炼）

参考截图的「质感」由 7 条可量化要素构成，与颜色无关、与**结构**有关：

| # | 要素 | 说明 |
|---|------|------|
| 1 | 粗墨描边 | 2px 墨色实线卡片描边，替代「无边框+柔影」 |
| 2 | 硬偏移阴影 | `4px 4px 0` 实色投影、零模糊——贴纸感核心 |
| 3 | 衬线大数字 | 宋体/衬线大号数字，杂志封面式标题层级 |
| 4 | 低饱和大色块 | 实色卡片，每屏 ≤2 块、面积 ≤40% |
| 5 | 编号 chip / 胶囊 | 墨底编号小方 chip + 描边胶囊标签 |
| 6 | 缝线虚线 | `dashed` 分隔线，手账装订感 |
| 7 | 按压位移 | 按下 `translate(2px,2px)` + 阴影收缩为 `2px 2px` |

## 二、玄黄适配原则：骨架照抄，颜色换血

参考图的高饱和撞色（明黄/淡紫/粉绿）直接搬会廉价化；玄黄的差异化正是
**用新中式低饱和色系替换**：宣纸底 + 墨色描边 + 黛青/赭石色块 + 鎏金点缀。
「新粗野主义的骨 × 新中式的皮」——网上没有现成的这个组合，是玄黄自己的记忆点。

## 三、设计令牌（原 → 新）

| 令牌 | 原 | 新 | 说明 |
|------|----|----|------|
| `--lj-bg` | 冷灰白 | **宣纸暖白 `#F7F3EA`** | 底色换血，叠 2% 噪点纸纹（SVG feTurbulence） |
| `--lj-card` | 纯白 | **`#FFFDF8`** | 卡片微暖 |
| `--lj-border` | 1px `#E2E4EA` | **2px `#2B2B26`（墨）** | 仅交互卡片；静态信息卡用 1px `rgba(43,43,38,.25)` |
| `--lj-shadow` | 模糊软投影 | **`4px 4px 0 rgba(43,43,38,.9)`** | 零模糊硬阴影 |
| `--lj-shadow-active` | — | `2px 2px 0` + `translate(2px,2px)` | 按压位移 |
| `--font-serif` | 无 | **Noto Serif SC / 霞鹜文楷** | 大数字、页面大标题；正文仍系统黑体 |
| 色块 | — | 黛青 `#3D5A5C`、赭石 `#B0684A`、藕粉 `#E8B4B8` | 复用现有 --color-*，实色填充 |
| 点缀 | 鎏金 `#C9A45C` | 不变 | 胶囊描边、进度、激活态 |
| 圆角 | 混用 | 卡片 16 / 按钮 12 / chip 全圆 | 全局收敛 |
| 分隔 | 实线 | `1px dashed rgba(43,43,38,.3)` | 卡内分区用缝线 |

## 四、克制条款（防廉价化，硬约束）

1. 硬阴影只给**可交互卡片 + 主按钮**；静态信息卡 1px 浅描边无阴影——全屏贴纸会灾难
2. 大色块每屏 ≤2 块、合计 ≤40% 面积
3. 衬线体只用于数字与页面级大标题，正文/按钮一律黑体
4. 不引入任何渐变/毛玻璃叠加在硬阴影体系上（两套质感互斥；现有 glassmorphism 逐步退役）
5. `prefers-reduced-motion` 时按压位移降级为透明度变化
6. 游戏牌桌（沉浸态 z-1600 体系）**不在本期范围**；PC 端后置单独评估

| 阶段 | 内容 | 交付 |

每阶段走常规链：eslint → build → 产物核验 → 部署 → 夜星自己看。

## 六、风险

- **鸿蒙 4 WebView**：衬线字体走系统宋体回退（Songti/serif），不另载字体包（0 带宽成本）；硬阴影是纯 box-shadow 无滤镜，鸿蒙 canvas 之外的 DOM 渲染无压力
- **暗色模式**：墨底 `#262521` + 描边改鎏金 `rgba(201,164,92,.5)`，硬阴影改深色版 `#000` 或降为描边——P2 时定稿
- **与 EP 组件冲突**：el-button/el-dialog 保留原生，只做皮肤级覆盖（:deep），不改 EP 结构
