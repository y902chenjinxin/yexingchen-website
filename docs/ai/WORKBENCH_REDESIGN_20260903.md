## 0. 目标

1. 废弃全屏首页 `/home`，登录后默认直达 `/workbench`。
2. 把首页玉简 3D 轮播作为"岛屿导航核心"搬到工作台顶部（主角感），数据面板在下方。
3. 新建全局顶栏，登录后全站常驻，整合品牌、全站导航、全局搜索、用户/音频控制。
4. 整体风格定为**冷峻东方 · 偏浅留白**：宣纸/绢帛浅底、黛青灰绿主调、玉简与卡片同系轻灵、苹果级毛玻璃。

## 2. 设计 Token（新增，追加到 variables.css）

基于 DESIGN_INKWASH 色板，收敛为"浅留白 + 黛青灰绿"一组业务 token：

```css
:root{
  /* 浅底 */
  --lj-bg: #f6f4ee;                 /* 宣纸留白主底 */
  --lj-bg-deep: #eeebe2;            /* 绢帛暗一度 */
  --lj-paper: #fbfaf6;              /* 卡片/面板底 */
  /* 墨黛主色 */
  --lj-ink: #3a4350;                /* 黛青近墨，主文字 */
  --lj-dai: #4a5f63;                /* 黛青，主强调 */
  --lj-dai-deep: #3d4f52;
  --lj-mist: #7f8d8d;               /* 灰绿次要 */
  /* 点缀 */
  --lj-ochre: #b0805a;              /* 赭石（少量）*/
  --lj-vermilion: #b55a48;          /* 朱砂（印章点睛）*/
  --lj-line: rgba(74,95,99,.16);    /* 淡墨细线 */
  --lj-line-strong: rgba(74,95,99,.3);
  /* 文字 */
  --lj-text: #39434b;
  --lj-text-2: #5f6b70;
  --lj-text-3: #9aa3a5;
  /* 毛玻璃 */
  --lj-glass: rgba(251,250,246,.62);
  --lj-glass-blur: saturate(180%) blur(20px);
  --lj-shadow: 0 6px 24px rgba(58,67,80,.08), 0 1px 3px rgba(58,67,80,.05);
}
```

> 迁移成本控制：新增 `--lj-*` 前缀，不覆盖 `--xiu-*`。第一轮只改工作台 + 顶栏 + 玉简；岛屿内页重构时再统一替换。

## 3. 玉简轮播组件 `JadeCarousel.vue`

抽自 HomeView，独立心用 8 张配置入参（也可默认内置 8 张）。

### 3.1 数据（玉简配置）

```js

  { key:'music', rune:'音', label:'宫商流转', path:'/island/music/inner', color:'#4a5f63' },
  { key:'novel', rune:'書', label:'卷帙浩繁', path:'/island/novel/inner', color:'#b0805a' },
  { key:'video', rune:'影', label:'光影交织', path:'/island/video/inner', color:'#5b6b7a' },
  { key:'log',   rune:'墨', label:'翰墨丹青', path:'/island/log/inner',   color:'#4a5f63' },
  { key:'tool',  rune:'器', label:'机关百变', path:'/island/tool/inner', color:'#6a7a6a' },
  { key:'notes', rune:'記', label:'笔记云台', path:'/notes', color:'#55706b' },
  { key:'assets',rune:'藏', label:'内容资产', path:'/assets',color:'#6b6a7a' },
  { key:'tasks', rune:'約', label:'任务镜台', path:'/tasks', color:'#7a5a5a' },
]
```

### 3.2 交互（保留完整）

- 3D 透视轮播（perspective 1500px），当前位最大最前、两侧扇形收缩 → 沿用 HomeView `getCardStyle`。
- 点击玉简 → `router.push(path)`（进内景/主工作区）。
- 鼠标拖动、触摸、左右键切换；hover 高亮 + 光晕 + 音效（沿用 `useIslandSound`）。
- 底部**小圆点**指示当前位。
- 空闲自动回位到初始位（可选，小天循环）。

### 3.3 视觉

- **竖条简**：高宽比 ≈ 4:3 竖屏（如 132×176px）。
- **毛玻璃羊脂青玉釉**：
  - 底层 `background: var(--lj-glass)` + `backdrop-filter: var(--lj-glass-blur)`，后层浅色透光。
  - 叠加羊脂玉釉渐晕 `radial-gradient` 高光 + 冰裂纹 `conic/linear` 纹理 + 顶部高光条。
  - 淡墨描边 + 玉色内侧细线（呼应 DESIGN_INKWASH `jade-card`，但改黛青冷调）。
- **专属 SVG 篆符**：每 key 一个 `<svg>`，道纹为篆/云纹路径，居中；下方小字标签。

## 4. 全局顶栏 `GlobalTopBar.vue`

登录后全站常驻（挂 App.vue），置于**桌宠上层**。

- 形态：**悬浮磨砂**，半透明 + 高辉度毛玻璃，随滚动淡出/收起。
- 左侧：品牌 logo（篆"玄黄"字 + 缩小玉简图标），点击回 `/workbench`。
- 中部：全站导航（笔记/任务/内容资产/岛屿）——后台静默，不喧宾夺主，但功能可达。
- 中部/右侧：**全局搜索**（即时联想跨笔记/资产/任务/标签，回车进 `?q=`）。
- 右侧：用户区（头像/道名 + 下拉：改头像/改密码/编年史/灵根测试/帮助/音乐音效开关/退出）——承接 HomeView 原有功能（弹窗用内联折叠，不二次弹窗）。
- 移动端：仅品牌 + 用户头像 + 收起搜索输入为图标。

> 复用 HomeView 现有弹窗模板（头像/密码/编年史/灵根测试）与 `useIslandSound` 音效逻辑。
