# 项目简介

更新时间：2026-08-27

## 产品名称

玄黄

## 当前定位

基于既有个人网站逐步建设的单用户个人工作台。

## 核心目标

- 记录富文本笔记和零散想法。
- 管理网页链接、图片和 PDF。
- 使用标签、分类、搜索和最近编辑组织内容。
- 通过云端 AI 整理笔记、生成摘要、提取标签并转成轻量任务。
- 保留现有网站模块，在不推倒重来的前提下逐步扩展。

## 当前产品边界

- MVP 内容：富文本笔记、网页链接、图片、PDF。
- MVP 任务：轻量待办，不做复杂项目管理。
- MVP 存储：服务器本地磁盘，不做备份。
- MVP 多端：响应式 Web + PWA，必须联网。
- AI：云端 API，供应商待定；高风险操作必须确认。
