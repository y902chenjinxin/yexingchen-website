# 玄黄 MVP 集中返工任务

## 目标

根据 `MASTER-mvp-review-2026-08-28.md` 修复玄黄 MVP，不拆成多个需要用户传话的小任务。完成后一次性汇报，交给 Codex 综合验收。

## 必须先修复（P0）

1. 统一后端工作台 API 与前端 Axios 响应契约。
   - 真实 API 和前端读取方式必须一致。
   - 新增真实接口契约测试，不能只用带 `data` 的 mock。
2. 修复受保护图片/PDF的预览和下载鉴权。
   - 不能公开匿名接口。
   - 可使用 blob/object URL、带鉴权的资源请求或安全短期 URL。
   - 确保图片插入笔记后真实可显示。

## 必须修复（P1）

3. 实现笔记编辑器粘贴图片和拖拽图片上传。
4. AI 调用统一为 preview → 用户确认 → invoke。
5. 完成 AI 结果确认应用：摘要、整理结果、标签和任务草稿。
6. AI invoke 显式携带并校验 conversation_id。
7. 完成 AI 对话与笔记/资产/任务的关联闭环，或明确修订文档并汇报。
8. 修复笔记附件加载和解绑：后端返回关联 ID，解绑必须落库。
9. 修复全局搜索 page offset。
10. 对网页 URL 做 http/https 和长度校验。
11. 文件上传改为可靠的大小、MIME、内容校验；避免无上限全量读入内存。
12. 文件下载/预览使用合适的流式或安全资源方式。
13. 文件物理清理失败时不得直接丢失数据库引用，支持保留、重试或明确错误状态。

## 约束

- 不连接生产服务器。
- 不执行生产迁移。
- 不推送 GitHub。
- 不使用真实密钥。
- 不删除旧 `/home`、音乐、小说、视频、日志、工具模块。
- 不全量格式化旧代码。
- 所有 schema 变更使用 Alembic。
- 新增真实行为测试，不能通过修改测试来掩盖问题。

## 最终必须验证

```text
python -m compileall -q backend/app backend/tests backend/alembic
pytest backend/tests -q
pip check

cd frontend
npm run build
npm run test
```

另外必须验证：

- 真实后端响应可以被真实前端正确读取。
- 已登录用户可以真实预览图片和 PDF。
- 未登录或其他用户不能访问私有文件。
- 粘贴图片和拖拽图片有运行时测试或浏览器验证。
- AI 没有确认前不会 invoke；确认后结果才可应用。
- AI 对话发送到当前选中的 conversation。
- 附件关联和解绑真实落库。
- 搜索第 2 页不会重复第 1 页。
- 测试产物已清理。
