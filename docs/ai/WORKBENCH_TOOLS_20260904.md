# 工具统一管理 + 像素压缩 + 网安页脚 + 管理页分页 + 缩放收敛（方案与实施）

> 日期：2026-09-04　SW：`xuanhuang-v27`　状态：已实施并部署到现网 yexingchen.cn

## 一、背景与目标

用户本轮提出 5 点需求，核心是让「工具」成为可由管理页统一管理的一等公民，并补齐合规与交互细节：

1. 视频下载与 PDF 等内置工具在管理页看不到 → 需统一纳入工具管理。
2. 新增**像素压缩**工具，且必须在管理页可见。
3. 网页底部**网安标识**缺失，需全站加回（公安盾牌 + ICP备案 + 公安网备，可跳转官网）。
4. 浏览器**放大/缩小时适配不佳**，需优化（80% ~ 150% 桌面不破版）。
5. 所有管理页补充**分页**，默认 10 条、可切 10/20/50。

## 二、方案与取舍

### 1. 工具统一管理（内置工具入库）
- 存量 `Tool` 模型仅存外部工具（id 9/10 练字、中英文翻译），内置页面工具（去水印/PDF）散落在 DB 外，管理页不可见。
- **取舍**：不新增独立"内置工具表"，而是给 `tools` 表扩充三列，让**内置工具也登记为 DB 记录**，实现一张表统一管理：
  - `kind TEXT`：`builtin`（内置，路由跳转）/ `external`（外链，iframes）。
  - `is_enabled INTEGER`：上下架（下架前台不展示仍可管理）。
  - `sort_order INTEGER`：排序。内置置顶 `0,1,2`；外部工具 `100000+id` 后置，保证内置永远排前。
- **内置禁删**：后端口删接口校验 `kind==='builtin'` 直接拒绝，前端删除按钮置灰，只能改下架——防止核心工具被误删。
- 排序与上下架走既有 `PUT /api/tools/{id}` 更新字段，前端选中行 ↑↓ 交换 `sort_order`。

### 2. 像素压缩工具（`/tool/compress`，100% 纯前端）
- **硬约束**：禁止任何 `fetch`/后端地址/WebSocket，数据流转严格限制在浏览器本地，下载用 `<a href="blob:...">` 触发。
- 技术栈：`browser-image-compression`（CDN 按需）+ Canvas 兜底。
- 三模式：
  - **智能压缩**：自适应分辨率 + 动态质量，**防负优化**——若原图更优则标记"原图更优，未压缩"不产出劣质文件。
  - **自定义**：按目标大小（滑杆 50~2000KB）或按质量（10%~100%）。
  - **仅缩放尺寸**：按最长边（200~4000px）或按比例（10%~100%）等比缩放，不压质量。
- 边界处理：JPG/PNG/WEBP（GIF 转静态首帧）、多文件、单文件 ≤10MB、0字节拦截、串行队列逐张压缩（内置进度条，防大文件卡死/崩溃）、失败不中断、成功即刻回收（后端式 `revokeObjectURL`）。
- **取样题型复用规范**：图标/配色/隐私徽章复用工具库统一风格（`IslandInnerBase type="tool"` + `.ls-card` 玻璃材质）。

### 3. 全站网安页脚 `SiteFooter`
- 组件含：公安盾牌图标 + `皖公网安备34010402704746号`（→ `beian.mps.gov.cn`）+ `皖ICP备2026006516号`（→ `beian.miit.gov.cn`），均为可点击跳转的 `<a>`。
- 双主题接入：`App.vue`（工作台浅色宣纸）深/浅变体 + `IslandInnerBase`（岛屿深色）各自挂在底部内，保证"每个网页底部"都出现（用户硬性要求）。

### 4. 管理页统一分页（客户端）
- 取舍：数据量级小（现有 5~几十条），选**客户端分页**（`computed` 切片）而非服务端分页，改动小、无接口变更。
- 统一 `el-pagination`（`total, sizes, prev, pager, next`，默认 10，可切 10/20/50），切换每页数量后重置回第 1 页。
- 应用于工具/音乐/小说/视频四管理表格；搜索关键字过滤后仍按过滤结果分页。

### 5. 桌面缩放收敛（`main.css` 全局规则）
- 四管理页共用类名（`.manage-pane/.manage-toolbar/.pager-wrap`），故缩放收敛规则放**全局 `main.css`**，一处覆盖四页：
  - `≤1250px`：`.manage-pane` 内边距 30→24px。
  - `≤1100px`：内边距 20px、工具栏 gap 收紧、搜索框 260→200px、分页居中。
  - `≤820px`：内边距 14px、搜索框满宽、隐藏每页条数选择器、表格允许内部横向滚动（`min-width:620px`）。
- 与 `IslandInnerBase` 既有的 1100/760 断点协同，覆盖 80%~150% 桌面缩放视口。
