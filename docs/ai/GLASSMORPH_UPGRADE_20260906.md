# 全站「苹果毛玻璃」质感升级方案

- 日期：2026-09-06
- 作者：TRAE 助手
- 状态：待用户审阅方向
- 依据：用户「想要苹果毛玻璃那种质感，像登录也是那种感觉，整体样式不是太满意，想从外观开始一直打磨」

---

## 1. 目标

以**登录页玻璃卡**为工艺锚点，把全站各主题（登录深青、工作台冷峻浅留白、岛屿深墨琉璃、桌宠面板）从「半透明色块 + 硬描边」升级为**统一的 Apple 级毛玻璃材质**，并沉淀为可复用的玻璃系统。核心不是改配色，而是**升级玻璃的"工艺质感"**。

---

## 2. 现状快照（根因分析）

### 2.1 三套颜色体系各自为政

| 区域 | Token | 现状底色 | 玻璃工艺 |
|------|-------|---------|---------|
| 登录页 | `#0a1218` 家族 | 深青夜色 | 卡 `blur(12px)`、`.glass` `blur(16px)` |
| 工作台 | `--lj-*` | 浅宣纸留白 `#f6f4ee` | `--lj-glass: rgba(251,250,246,.62)` + `saturate(180%) blur(20px)` |
| 岛屿内页 | `--ls-*` | 墨青夜色 `#1a242c` | `--ls-glass: rgba(32,42,51,.62)` + backdrop-filter |
| 桌宠面板 | `--ls-*` | 墨青 | 同上 |

### 2.2 与「苹果毛玻璃」的差距

- **模糊强度/饱和度不统一**：登录 12px、工作台 20px、岛屿未统一，且 `saturate` 各组件不一致。
- **缺「上缘内高光」**：Apple 玻璃普遍有 `inset 0 1px 0 rgba(255,255,255,.06~.12)` 让玻璃"浮"起来；现多处没有。
- **阴影偏"硬"**：多用纯黑投影（`0 8px 32px rgba(0,0,0,.25)`），缺 Apple 特有的「多层柔和偏移 + 接触阴影」。
- **缺表面噪声颗粒**：Apple 玻璃常叠加极淡噪点提升高级感；现仅 `.grain-overlay` 全局 2.5%，卡片级未加。
- **内容对比度保护不足**：毛玻璃后文字需在其下垫半透明底，避免发虚；部分面板文字浮在玻璃上对比不足。
- **圆角不一**：工作台 `--radius-lg 16px` 偏小；Apple 玻璃倾向更大圆角（18~24px）营造柔和。

---

## 3. 设计原则

1. **一种玻璃，三种肤色**：统一玻璃"工艺参数"，三套主题只改底色/主色，不改工艺。
2. **尊重现有水墨身份**：保留墨青夜色 + 流金点缀的东方气质，只把"玻璃做得更透、更柔、更高级"。
3. **可访问性第一**：玻璃下文字必须有足够对比（占位遮罩 + 清晰文字色）。
4. **性能友好**：`backdrop-filter` 有限度使用，避免大面积过度模糊（尤其移动端），可降级。

---

## 4. 玻璃系统设计（方案核心）

### 4.1 玻璃工艺配方（新 Token，进入 `variables.css`）

```css
/* ---- Apple 级玻璃系统 ---- */
:root {
  /* 通用玻璃参数 */
  --glass-blur: blur(24px) saturate(185%);
  --glass-border: rgba(255,255,255,.10);      /* 外层微亮描边 */
  --glass-highlight: inset 0 1px 0 rgba(255,255,255,.08); /* 上缘内高光 */
  --glass-shadow:                                  /* 多层柔和阴影 */
     0 1px 1px rgba(0,0,0,.04),                   /* 接触阴影 */
     0 8px 24px rgba(0,0,0,.10),                  /* 中距柔影 */
     0 24px 60px rgba(0,0,0,.18);                 /* 远距大气影 */
}
```

### 4.2 三套主题的"玻璃肤色"

| 主题 | 玻璃底（半透明） | 说明 |
|------|----------------|------|
| 浅·工作台 | `rgba(251,250,246,.55)` + 高模糊 | 明亮透气 |
| 深·岛屿内页 | `rgba(28,38,49,.55)` + 高模糊 | 夜色高级 |
| 深·登录 | `rgba(22,46,60,.60)` + 高模糊 | 与现状衔接 |

### 4.3 统一接入点（本次覆盖范围）

- `GlobalTopBar` 顶栏 → 玻璃悬浮
- 卡片容器（工作台玉简区、岛屿卡片墙、管理表格）
- `el-card` / `el-dialog` / 弹窗 → Element 主题覆盖
- 输入框 `el-input` / 按钮 → 玻璃描边 + hover 微光
- 底部 `SiteFooter` 页脚
- 桌宠 `WhaleCompanion` 面板

## 5. 与「苹果感」对齐的质感细节清单

1. **上缘内高光**：所有玻璃卡加 `inset 0 1px 0 rgba(255,255,255,.07)`，底部加 `inset 0 -1px 0 rgba(0,0,0,.05)`。
2. **柔和多层投影**：弃单一硬黑影，用 3 层（接触/中距/大气）柔和影。
3. **背景需"有色彩可透"**：玻璃要透出后面的彩色（渐变/光斑），工作台浅色下补淡彩径向光斑，避免透出纯白导致"假透明"。
4. **卡片级噪点**：玻璃层叠一层极淡 SVG 颗粒（`opacity .02`），提升"磨砂"真实感。
5. **hover / focus 微光**：玻璃卡 hover 时描边变亮 + 泛弱光，focus 输入框外层光晕。
6. **内容对比度遮罩**：文字/图标密集区下方垫一层 `rgba(背景色,.5)`，确保清晰。
7. **大圆角**：主卡片圆角上调 18~24px，按钮/输入框保持适中。
8. **动效克制**：`backdrop-filter` 变化用 `transition` 平滑，禁用突兀弹入。

## 6. 落地步骤（分阶段，每阶段可部署可回滚）

- **Phase 1（玻璃基座）**：新增玻璃 Token 到 `variables.css`，定义 `.glass-card` 通用类，替换工作台卡片、顶栏。
- **Phase 2（岛屿深色）**：`IslandInnerBase` + 五模块卡片墙接同一玻璃类，统一深色配方。
- **Phase 3（控件）**：Element Plus 主题覆盖（输入框/按钮/弹窗/消息），统一圆角与微光。
- **Phase 4（质感细节）**：噪点、内高光、多层影、hover 微光、登录页微调对齐。
- **Phase 5（验证）**：本地 + 生产浏览器取证，缩放/移动端适配回归；更新 WORK_LOG / CSS 文档。

---

## 7. 验收标准

- 全站关键容器为统一玻璃材质（同一 blur/saturate/内高光/阴影配方）。
- 工作台浅色下玻璃"透出淡彩"而非假白透明；岛屿/登录夜色下玻璃高级不透闷。
- 文字在玻璃上对比度达标（可读，不发虚）。
- 缩放 80%~150%、窄屏移动端不破版。
- 桌面/移动端 `backdrop-filter` 无性能卡顿（必要时降级）。

---

## 8. 待用户确认的取舍

- **配色是否保留**：只升级玻璃质感、保留现有墨青+流金配色，还是顺带微调主色？
- **范围**：是否本次覆盖登录页一起对齐（建议含），还是先做工作台+岛屿、登录页最后？
- **动效强度**：微光/悬浮是否全开，还是克制版？
