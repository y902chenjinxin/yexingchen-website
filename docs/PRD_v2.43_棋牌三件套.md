## 一、目标与范围

在「娱乐」分组下新增 **大富翁 / 麻将 / 掼蛋** 三个独立菜单项，全部支持「开房间 + 人数不足自动补机器人 + 在线邀请家人 + 观战」，并引入 **积分 ↔ 欢乐豆** 经济系统。视觉参考腾讯棋牌质感，游戏页使用**独立皮肤**，不影响全站玄黄主题。

**上线节奏：三款一起上线**（开发顺序掼蛋先行，作为通用底座验证）。

## 二、通用底座（三款共用）

| 项 | 决策 |
|---|---|
| 入口 | 「娱乐」分组下**三个独立菜单项** |
| 开房 | **复用现有邀请机制**：选家人 → 建房 → 对方收到邀请 → 接受入局 |
| 机器人补位 | 开房时按真人数量自动补 AI 到满座 |
| 观战 | 入口 = 游戏页「正在进行的牌局」列表；观战者**只能看公开信息，看不到任何手牌** |
| 出牌计时 | **不限时**（无倒计时、无自动托管） |
| 掉线 | **AI 立即接管**，人回来可收回手牌继续打，牌局不中断 |
| 主动退出 | **按当前进度结算**豆子，牌位由 AI 接管 |
| 再来一局 | 结算页一键「再来一局」，同房间同配置直接开新局 |
| 局内交流 | **快捷短语 + 表情**，不支持自由打字 |
| 音效 | **只做操作音效**（发牌/出牌/胡牌/骰子/胜负），一键静音，**无背景音乐** |
| 底注档位 | 开房时选（默认 100 / 500 / 2000 豆） |
| 手机朝向 | **三款全部横屏** |
| 防沉迷 | 不做 |
| 屏幕模式 | 只有**大富翁支持同屏**（信息全公开）；麻将/掼蛋只走开房 |

## 三、掼蛋（开发优先级 1）

**开源资产**：`Mereithhh/guandan-lab`（Apache-2.0），规则基线为 2022《竞技掼蛋竞赛规则（试行）》，自带 32 项规则一致性检查 + 176 项测试。**需在项目中保留 NOTICE 归属声明。**

### 玩法规格

- 两副 108 张**唯一牌 ID**，四人 2v2。
- 牌型：单张、对子、三张、三带二、顺子（5 张）、连对（3 对）、钢板（2 个三张）、炸弹（4 张及以上）、同花顺、四大天王。
- 特殊机制：**级牌**、**逢人配**（红桃级牌作万能牌，界面显示「配」并解释本手具体替代关系）、**进贡 / 还贡 / 抗贡**、**接风**、**对家配合升级**、**打 A / 过 A**。
- 人数语义：
  - **1 人** = 1 真人 + 3 AI
  - **2 人** = 2 真人 + 2 AI，**开房时让玩家自选组队模式**（两真人同队 / 两真人各带 1 AI 对立 / 随机分座）
  - **4 人** = 4 真人
- 结算：**底注 × 升级数**。
- 新手引导：复用现有「游戏说明」按钮，**图文规则说明**（牌型 / 逢人配 / 进贡还贡 / 接风）。

### AI

**本地规则 AI**，直接移植 guandan-lab 的三个 Agent（王总·稳健控场 / 小顾·搭档优先 / 林姐·效率突围）。难度**随人数自动调整：真人越少 AI 越弱**。

## 四、麻将 · 四川血战到底（开发优先级 2）

**开源参考**：`kobalab/Majiang` 三件套（MIT）——借用其**向听数 / 和牌 / 和了点**算法思路；但**番种与流程按四川规则自研**。

### 玩法规格（标准核心）

- **定缺**：开局必须选一门缺，缺门牌不能胡。
- **血战到底**：有人胡牌后不封顶，继续打到只剩一家。
- **刮风下雨**：明杠 / 暗杠即时收付，杠上花 / 杠上炮翻倍。
- **查大叫 / 查花猪**：流局时未听牌方赔付。
- **不含**：换三张、呼叫转移（后续可加）。

### 人数与结算

- 始终 **4 个牌位**：**1 人** = 1 真人 + 3 AI；**2 人** = 2 真人 + 2 AI；**4 人** = 4 真人。
- 结算：**底注 × 番数，逐家结算**。

### 辅助提示

**听牌提示 + 舍牌危险度分析**，**默认开启、游戏内可关**。

### AI

**本地规则 AI**：向听数 + 牌效 + 舍牌危险度算法。难度**随人数自动调整：真人越少 AI 越弱**。

## 五、大富翁（开发优先级 3）

**实现路径：完全自研**（MIT 干净，不受 GPL 传染）。仅借鉴 `mine-monopoly` 的系统设计思路（角色 / 可编程机会卡 / 修饰器）。

### 玩法规格

- **棋盘**：**52 格大棋盘**，**等距 3D 中国城市地图**（北京 / 上海 / 广州 / 成都…），暖木色调。
- **人数**：**1~8 人任意**，不足 8 人自动补 AI。
- **核心机制**：买地 / 盖房升级 / 收租 / 机会命运卡 / 监狱 / 税收 / 抵押 / **玩家间交易** / **拍卖**（流拍与破产地块进入拍卖行） / 破产淘汰。
- **初始资产**：固定（建议 50000 豆），**破产即淘汰**退出本局（可继续观战），**最后一人存活者胜**。
- **同屏模式**：支持（一台设备轮流操作）。

### 8 个角色技能（8 角色各带 1 个，开局选角色）

① 掷骰加成（可重掷）② 免租一次 ③ 强买邻地 ④ 拆迁令 ⑤ 双倍收租 ⑥ 闪现（瞬移任意格）⑦ 均富（与最富者现金拉平）⑧ 抄底（7 折买对手地块）

### 8 张道具卡（踩地图「道具格」随机抽）

① 路障 ② 传送 ③ 免费卡 ④ 均富卡 ⑤ 购地卡 ⑥ 转向卡 ⑦ 怪兽卡（拆房）⑧ 天使卡（免灾）

### 地图编辑器（全功能）

- 可视化**拖拽画棋盘** + 配置地块（地名 / 地价 / 颜色 / 事件文案）+ 用代码写**自定义玩法逻辑**（角色技能 / 卡牌效果 / 地图事件）。
- 地图**家庭共享**（与本站 household 设计一致），并支持**导出 / 导入 JSON**。
- 注意：编辑器是**工作量最大**的一块，排在最后。

## 六、积分与欢乐豆经济系统

### 积分获取

| 来源 | 规则 |
|---|---|
| 每日签到 | +10 / 天；连续签到 7 天额外 +50 |
| 日常行为 | 记账 / 笔记 / 体重记录 各 +1，**每日封顶 +10** |
| 游戏对局 | 参与 +2 / 胜利 +20 / 连胜每连 +5 |

### 积分 ↔ 欢乐豆

- **手动兑换**：**100 积分 = 10000 豆**（汇率可配）。
- 兑换入口在个人中心「积分中心」。

### 欢乐豆

- **独立钱包**（每人一个），**可赠送家人**：**每日限额 20000 豆，直接到账**（不弹确认窗）。
- **破产保护**：豆 < 5000 时，**每日可领一次 5000 救济金**。
- **新用户**赠送 10000 豆。
- **局内结算按游戏规则**：麻将 底注×番数逐家结算；掼蛋 底注×升级数；大富翁 初始资产 + 破产淘汰。

### 积分中心（放在**个人中心**内）

包含四块：**余额 + 明细** / **兑换 + 赠送** / **领取救济金** / **家庭排行榜**。

### 战绩与排行

**家庭内排行榜**：三款游戏各自统计局数 / 胜率 / 最高连胜，在生活岛展示。

## 八、技术架构

### 规则引擎位置

**统一移植成 Python**，跑在现有 FastAPI 进程内（不引入 Node 侧车，不新增第二套服务）。

- **麻将 / 掼蛋：服务端权威**——手牌绝不下发到浏览器（否则可看源码作弊），服务端只向每位玩家投影自己的手牌 + 公开信息。
- **大富翁：信息全公开**，可前端计算 + 服务端记录事件流（沿用现有棋类的荣誉制）。

### 通信

沿用现有 `game_rooms.py` 的**轮询同步**骨架；牌类节奏慢，1~1.6s 轮询足够，**不引入 WebSocket**。新增：观战订阅、AI 接管状态位、再来一局。

### AI 实现

**本地规则 AI（确定性算法）**，不调用大模型、不消耗 token、不作弊（只基于公开信息决策）。这也符合「不新增第二套 AI 配置」的项目约束。

### 数据模型（新增表草案）

| 表 | 用途 |
|---|---|
| `game_wallet` | 每人积分余额 / 欢乐豆余额 |
| `point_ledger` | 积分收支明细（来源、数值、时间） |
| `bean_ledger` | 豆子收支明细（对局结算、赠送、救济金、兑换） |
| `game_stats` | 三款游戏的家庭战绩（局数 / 胜率 / 最高连胜） |
| `monopoly_map` | 自定义地图（作者、家庭共享标记、JSON 内容） |
| `game_rooms`（扩展现有） | 新增 `game_key`（monopoly/mahjong/guandan）、`base_stake`、`ai_seats`、`spectators` |
