# PRD · 牌类在线对局（掼蛋 / 麻将 / 大富翁）v2.44

> 状态：**待你复核后开工**。本文汇总 2026-10-04 九轮问答的全部结论，取代 PRD_v2.43 §8 的"后续排期"口径。
> 前置：v2.43 已上线的三款牌类（前端同屏 + 经济系统），本版把它们改成**服务端权威的在线房间对局**，并补齐规则与 UI。

---

## 一、目标与范围

**目标**：掼蛋 / 四川麻将 / 大富翁 三款牌类，支持**建房邀请家人 → 等待房 → 跨设备对局 → 结算豆子 → 再来一局**的完整闭环，手牌由服务端权威保管（防看牌）。

**三款一起做**（共用同一套底座），按 掼蛋 → 麻将 → 大富翁 的顺序实现，最后一起上线。

## 二、模式改造（删 / 留 / 加）

| 游戏 | 现状 | 本版 |
|---|---|---|
| 掼蛋 | 单人·3AI / 双人同屏 / 四人同屏 | **删「双人同屏 / 四人同屏」**；**留「单人 · 3 AI」练习**；**加「在线 · 邀请家人」** |

| 大富翁 | 2/4/6/8 人（含同屏多人） | 本地只留 **「单人 · N AI」练习**；**加「在线 · 邀请家人」** |

- 在线入口：在现有 `/tool/games` 的游戏详情里**多一张模式卡「在线 · 邀请家人」**，点它进**独立等待房**。
- 同屏多人（一台设备多真人轮流）**整体下线**（保留单人练习）。

## 三、服务端权威架构

### 3.1 规则引擎位置

**掼蛋 / 麻将：规则引擎移植成 Python**，跑在现有 FastAPI 进程内（不引入 Node 侧车、不新增第二套服务）。

- 发牌、摸牌、判定（牌型/和牌/番/听牌/向听）、AI 决策**全部在服务端**。
- **手牌绝不下发**：`GET /rooms/{id}` 对每个请求者只返回**自己的手牌** + 公开信息（各家手牌张数、牌河、最近出牌、轮到谁、剩余牌墙）。
- 服务端**逐手校验**：轮次归属、出的牌是否在本人手牌内、牌型是否合法、能否压过上一手。

**大富翁：信息全公开**，规则引擎同样放 Python（要服务端权威处理交易/拍卖/抵押/破产），但无需隐藏信息。

### 3.2 通信

沿用 `game_rooms.py` 的**轮询同步**骨架（1.6s），不引入 WebSocket。牌类节奏慢，够用。

### 3.3 AI

- 服务端 Python 规则 AI（确定性、不作弊、只基于公开信息 + 自己手牌决策）。
- 在线补位 AI **固定「标准」难度**，开房不选。

## 四、房间与席位

### 4.1 进房方式
**邀请指定家人**：沿用现有 `MemberPicker` → 发邀请 → 对方在顶栏提醒里接受 → 进入等待房。

### 4.2 席位
- 掼蛋 / 麻将：**固定 4 席**；大富翁：**2–8 席**。
- **房主手动开局**：房主点「开始」时，空席由 AI 补位。
- **最少 2 个真人**才能开局（1 个真人的情况请玩单人练习）。
- **开局后席位锁定**：AI 补的位不再让真人替换；真人掉线席位由 AI 接管（可夺回）。

### 4.3 房主权限
**踢人 + 拖拽换位**（掼蛋要分队友，座位决定队伍）。

### 4.4 房间生命周期
- 一局打完**房间保留**，房主可「再来一局」原位重开；**每局重选底注**。
- 所有人退出后房间销毁；**30 分钟无心跳自动销毁**。

### 4.5 掉线 / 退出
- **掉线**：30 秒无心跳 → AI 接管；玩家重进房间**立即夺回**控制。
- **主动退出**：＝认输，按当时名次结算豆子，剩余牌局由 AI 接手打完，其他人不受影响。

## 五、豆子结算

- **底注档位**：100 / 500 / 2000 豆。**开局前每人预扣一份底注**，结束时按赔率多退少补。
- **AI 不参与结算**：只算真人之间的输赢，AI 拿到名次不赔不赚。
- **赔率（常见棋牌口径）**：
  - **掼蛋**：双下每人赔 底注×3、一三 ×2、一四 ×1。
  - **麻将**：按番数 × 底注（含刮风下雨的即时收豆）。
  - **大富翁**：初始资产 50000 豆，破产出局，最后存活者吃剩余资产。
- 豆不足走既有**救济金**（豆 < 5000 每日领 5000）。

## 六、规则补齐

### 6.1 掼蛋：进贡 / 还贡 / 抗贡（**新增**）

一局结束后，败方向胜方进贡：

1. **谁进贡**
   - **双下**（胜方两人拿 1、2 名）→ 对方两人**都进贡**。
   - **单下**（只有 1 人赢）→ **末游进贡**。
2. **贡牌怎么选**：手上**最大的一张**，但**红桃级牌（逢人配）不用于进贡**。
3. **双下时贡牌归属**：**不按名次**——两张贡牌**比大小，大的给头游，小的给二游**。
4. **先出牌的人**：**贡牌大的那位**先出牌。
5. **还贡**：收贡方回一张 **≤ 10** 的牌（不能还级牌、不能还王）。
6. **抗贡**：进贡方**合计**持有**两张大王**则不用进贡；此时由**上一局头游（第一个走的人）先出牌**。
7. **交互**：**进贡自动**（系统按规则挑牌）、**还贡手动选**（≤10，带 30 秒倒计时）。

### 6.2 麻将：刮风下雨（**新增**）

- **明杠（刮风）** 即时收 1 倍底注；**暗杠（下雨）** 即时收 2 倍底注；胡牌时再按番结算。

### 6.3 大富翁：交易 / 拍卖 / 抵押（**新增**）

- **玩家间交易**：**随时可发起**；标的 = **地块 + 现金 + 道具卡**任意组合；对方可接受 / 拒绝 / 还价。
- **拍卖**：房主（停在地块的玩家）**不买即触发全场公开拍卖**；**固定加价档**轮流出价，无人加价则成交。
- **抵押**：可抵押地块换取现金，赎回按标准利息。
- **破产**：资产**归债主**（谁触发破产谁拿走全部地产与现金）。

## 七、UI 规范

### 7.1 牌面（三款通用）
- **立体质感**：投影 / 内阴影 / 高光，像真实牌张。
- **特殊牌高亮**：大/小王、级牌、逢人配用颜色 + 角标强区分。
- **选中态强化**：上浮 + 描边 + 光晕。
- **花色更清晰**：♠♥♣♦ 加大居中，点数易读。
- **牌背纹样**：对手手牌用精美牌背，不再是纯色块。
- **hover 放大预览**：悬停牌张放大（手牌密集时有用）。

### 7.2 手牌区
- **一屏展示全，不滑动**：按手牌张数**自适应缩窄 / 重叠度自适应**（27 张也能全显）。
- **选牌效率**：
  - PC：**Shift + 首尾点选**，两点之间的牌全选。
  - 手机：**滑动划选**（划过的牌依次选中，滑回取消）。
- **可压牌高亮**（掼蛋）：能压过上一手的牌自动描边。

### 7.3 出牌区
- **出牌方光效**：当前出牌方加高亮光效，避免误解。
- **出牌历史**：**右侧竖栏**，最新在上，**可上下滑动**回看（不再错过）。
- **上一手残影**：中央保留上一手出牌残影，可点开回看。
- **出牌飞行动效**：选中的牌从手牌飞到中央，轻微上抛；被吃的牌原地炸开淡出。

### 7.4 麻将专属辅助
- **缺门灰显**：缺门牌置灰并提示优先打出。
- **危险牌提示**：**生张标红**（别人缺门之外、没出过的牌，可能点炮）。

### 7.5 牌桌
- **默认配色各游戏独立**：掼蛋墨绿绒面、麻将墨绿绒面、大富翁等距 3D 城市地图；牌桌内**可换色**（墨绿 / 深蓝 / 酒红）。
- **等待房**：**独立等待房页**——显示 N 个席位（已进 / 空位）、房主可踢人 / 换位、点「开始」空席 AI 补位。

### 7.6 手机端
- 进入牌桌时**浮层提示「请横屏游玩」**，并**尝试用屏幕方向 API 自动锁定横屏**，失败则只提示。

### 7.7 战绩
- **不单独做战绩页**，沿用个人中心「积分中心」里已有的战绩与家庭排行榜。

## 十一、待办 / 风险

1. **规则双实现**：掼蛋/麻将规则在前端 JS（同屏练习用）与后端 Python（在线用）各一份，**必须做一致性回归**，否则同屏与在线手感不一致。
2. **进贡规则**为本项目自定义口径（双下按贡牌大小分配、抗贡合计判定），需在上线前用固定牌例做单测。
3. **大富翁交易/拍卖/抵押**是本期最大工作量块，建议 P3 内单独排期。
4. **大富翁一局时间长**（可能 30 分钟+），需确认房间超时（30 分钟无心跳）不会误杀进行中的对局——进行中房间按"有心跳即续期"处理。
5. 掼蛋/麻将在线的**服务端 AI** 需与前端 AI 强度对齐（都取"标准"）。
