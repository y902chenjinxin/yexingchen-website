### mine-monopoly 的亮点（值得借鉴的设计）

- **地图编辑器**：拖拽式画棋盘、配地块、写事件逻辑，用 TS 写自定义玩法；内置 MCP 服务做 AI 辅助生成角色/卡牌/事件。
- **角色系统**：每个角色有独特技能 + 修饰器（增益/减益模板）。
- **机会卡可编程**：卡牌效果用 TypeScript `effectCode` 编写。
- **游戏阶段**：回合阶段与规则集可配置。
- **混合 P2P**：主机客户端在 Web Worker 里跑游戏逻辑（不阻塞 UI），玩家间 WebRTC 直连，中央服务器只管认证与房间路由。

### 为什么不建议直接移植

1. **GPL-3.0 传染**：整站会因此被迫 GPL 开源，风险太大。
2. **没有 AI 机器人**：而你的硬需求是「8 人不足自动补位」——无论如何都要自己写 AI。
3. **架构不兼容**：它是 `client/server/admin/map-editor` 多应用 monorepo + MySQL + coturn，现有站是单 FastAPI + SQLite。
4. 项目 README 明确写「不建议自行部署」。

### 推荐：自研（MIT 干净），借鉴其系统设计

规则引擎（买地/收租/盖房升级/机会命运卡/监狱/税收/抵押/拍卖/破产/交易）+ 8 人座位 + AI 补位，自研可控且能完全按「中国城市地图 + 腾讯棋牌风」定制。

### 关键矛盾（需要你拍板）

**GitHub 上没有成熟的「国标 / 四川 / 广东」麻将 Web 实现**——现成引擎清一色是日麻。所以：

### 推荐：抽 `guandan-lab` 的规则核心 + 自研腾讯风 UI

它的 `lib/game` 是**零 I/O 的确定性规则核心**，这是最难写、也最值得直接拿的部分：

- 两副 108 张**唯一牌 ID**，四人对局，**规则引擎校验所有动作**
- 覆盖：**级牌 / 逢人配（红桃级牌当万能牌，界面会显示「配」并解释替代关系）/ 进贡还贡 / 抗贡 / 接风 / 对家配合升级 / 打 A**
- 服务端权威在线房间：**只向玩家投影自己的手牌**、版本化动作日志、刷新重连、2 分钟无操作取消
- 无密钥也能跑完整本地 AI 对局（AI 只基于公开信息，不作弊）

唯一代价：它是 Next.js 工程，需要把 `lib/game` 抽出来接进现有 Vue + FastAPI。

### 自研成本（若不走上面这条路）

掼蛋比斗地主多出：两副牌、级牌、逢人配、进贡/还贡/抗贡、接风、对家配合升级、打 A/过 A。目前**没有可直接复用的「掼蛋牌型判定 + 出牌合法性」独立库**，自研成本明显高于斗地主。

## 五、UI 风格方案（参考腾讯棋牌）

调研到的腾讯棋牌视觉特征：

- **《欢乐麻将》**：中国风元素（竹子 / 墨笔 / 旗袍）、**深绿色桌布**底色、四名玩家分坐四个方向、玩法与底分**印在桌布上**、麻将牌做成 **3D 立体**、牌面干净简洁。
- **《欢乐斗地主》**：**轻量化 / 扁平化**、配色从浓郁转向**明亮**、牌桌改为**蓝色**、**手牌尺寸放大**、3D Q 版角色、头身比拉高。

### 落地到本站

| 元素 | 方案 |
|---|---|
| 牌桌 | 麻将：**墨绿绒面** + 极细织物纹理 + 暗角；扑克：**蓝绿渐变**桌布；大富翁：**暖木色棋盘** |
| 牌面 | 圆角 + 厚度感（多层阴影模拟「立牌」）+ 顶部高光；麻将牌做立体侧边 |
| 玩家席位 | 头像 + 昵称 + 分数胶囊，四方位（下/上/左/右），当前回合席位外发光 |
| 操作区 | 吃碰杠胡 / 出牌 / 要不起 —— 做成腾讯那种**贴在手牌下方浮起的胶囊按钮**，不是居中弹窗（与本站「无弹窗」硬约束一致） |
| 动效 | 发牌飞入、摸牌上浮、出牌抛掷、胡牌粒子；遵守 `prefers-reduced-motion` |
| 与玄黄主题的关系 | **游戏页做独立皮肤**：进游戏切腾讯风牌桌，退出恢复玄黄主题；不进游戏不污染全局 |

## 六、接入方案（复用现有设施）

现有骨架可直接复用：`game_rooms.py`（房间/邀请/1.6s 轮询/悔棋）、`GamesView.vue`、`useGameRoom`。

1. `GAMES` 注册表新增三个 key：`monopoly` / `mahjong` / `guandan`。
2. 房间/邀请/轮询沿用现有机制；**麻将与掼蛋的权威状态放服务端**（防作弊，且掼蛋 guandan-lab 本来就是服务端权威），大富翁可沿用「客户端计算 + 服务端记录事件流」的荣誉制（家庭场景够用）。
3. **机器人补位**：开房时按 `human_count` 自动补 AI 座位（麻将/掼蛋补到 4 座，大富翁补到 8 座）。
4. 人数语义（**待确认**）：
   - 麻将 / 掼蛋「1 人」= 1 真人 + 3 机器人；「2 人」= 2 真人 + 2 机器人；「4 人」= 4 真人。
   - 掼蛋本质是 4 人 2v2，「2 人」时两个真人可设为**同队**或**对立**（推荐同队 + 2 个 AI 补位，保持 2v2 结构）。
   - 大富翁「8 人」= 最多 8 真人，不足补机器人。
