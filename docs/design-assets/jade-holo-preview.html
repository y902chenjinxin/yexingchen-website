玉简闪光卡 · 效果预览

把鼠标移到卡片上——卡片会跟着倾斜，镭射箔面随指针扫过，篆符与标签因为处在不同 Z 深度会产生真实视差。
本页直接引用项目的 variables.css，配色与线上完全一致。

当前：日间主题 · color-dodge 换成 overlay（避免亮底刷白）

四层 Z 深度：玉体 z=0 → 篆符 z=22 → 镭射箔面 z=38 → 标签 z=54。标签刻意压在箔面之上，保证文字不被反光糊掉。

倾角封顶 ±12° / ±14°：超过这个角度文字可读性与「反光可信度」都会崩，这是全息卡的业界经验值。

昼夜差异：夜间用 color-dodge 加光叠色（箔面最显）；日间亮底会被刷白，所以切 overlay 并把强度从 .58 压到 .42。切到夜间看看区别。

零依赖：整页只有 CSS 变量变换与 mix-blend-mode，没有 WebGL、没有 Three.js、没有第三方库。
