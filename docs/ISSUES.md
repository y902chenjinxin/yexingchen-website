## v2.46.146 暴力摩托补回「选赛道 + 选车」（2026-10-20）

- **V246146-001 「移植」要连开局流程一起搬，不能只搬跑图那一段**：原作 Road Rash 的开局是「选赛道 → 选车 → 跑」，我们只搬了「跑」，于是夜星立刻察觉「我以前玩的是有这块内容的」。**移植一个玩法时先列一遍原版的完整流程节点（选人/选图/选车/结算/存档），逐个对照我们缺了哪个**，比只盯核心循环更不容易漏。
- **V246146-002 常量是「只有一种」时的写法，一旦要有差异就得先降级成数据**：`maxSpeed / ACCEL / 换道 15 帧 / 耐久 100 / 伤害 10` 原本是模块级 `const`，写死意味着「所有车手感必须一样」。加车款前的第一步不是写车款表，而是把这些值搬进 `makeBike()` 的实例属性（`maxSpeed / accel / laneCdMax / durability / damage / shape`），玩家车注入所选车款、对手仍走原基线 —— **改造顺序错了会出现「改了玩家速度连对手速度一起变」的连锁回归。**
- **V246146-003 纯景观差异不要顺手改数值**：4 张赛道只换天空/远山/地面/路肩/景物/天象，路程、对手数、路障节奏一律不动 —— 否则「换地图」就变成「换难度」，玩家没法单独评价地图好不好看。
- **V246146-004 选择项要能记住、也要能改**：赛道/车款落 localStorage（下局沿用），并在跑图顶栏留一个「换车 / 换赛道」按钮 —— 只让在开局选一次，等于每换一次都要退出重进。
- **V246146-005 属性面板别只给数字**：`statPips()` 把极速/加速/灵活/耐久归一到 1~5 格，四台车横着比一眼就够；纯数字表在手机端根本读不动。
- **V246146-006 赛前难度选择器要判「外层是否已给」**：游戏大厅进来时带了 `initialMode`（外层已选过难度），直达页进来没有。面板只在 `!props.initialMode` 时显示难度档，同一份 UI 兼顾两个入口又不重复提问。

## v2.46.145 修全站双网安/备案标识（重复页脚）（2026-10-20）

- **V246145-001 页脚有两个「归属者」，判断口径必须只能有一个**：`App.vue` 全站贴一条 `<SiteFooter>`，`IslandInnerBase` 又在自己页面内贴一条，靠 `showGlobalFooter` 的**前缀白名单**决定谁出。问题是白名单写死在 App 里、而「谁自带页脚」的事实写在各自视图里 —— 两侧一旦不同步，新页面就会「页面内一条 + App 一条」并排两条备案（本次 `/play/*` 与 `/life/*` 就是这样）。**凡「全局默认 + 局部覆盖」这种双归属结构，覆盖清单不要手写在默认侧的代码里，要做到新增者能自动登记（如让外壳组件自行上报），或者至少把清单提成常量并写明"新增 X 必须同步这里"。**
- **V246145-002 「看不到某内容」的排查要按组件真实渲染树走，别猜**：全项目逐条比对的方法很轻 —— ① grep 页脚组件（`SiteFooter`）的**全部引用点**（只有 2 处）→ ② grep 外壳组件（`IslandInnerBase`）的**全部使用者**（29 个视图）→ ③ 把「用到外壳的路由」与「全局页脚排除清单」做差集。差集就是重复集，一次扫清，不用逐个页面开浏览器。
- **V246145-003 路由前缀判断别用字符串前缀正则**：旧写法 `^\/(music|novel|video|log|tool|history)` 会把 `/toolxxx` 这类「同前缀不同路由」也判成岛屿页（表现是该页少一条页脚）。改用 `p.split('/')[1]` 取首段做精确比对，语义与「一级模块」一致。
- **V246145-004 顺手核到 `LifeView` 一个组件挂两个路由**：`/life/weight` 与 `/life/meals` 共用同一视图，所以「漏登记一个前缀」会一次坏两个页面 —— 修前缀时按**前缀**而不是按**页面**计数，才不会漏。

## v2.46.144 娱乐模块接入两款单机游戏（2026-10-20）

- **V246144-001 大体积第三方资源要放在 nginx 而不是构建产物里**：PvZ 整包 132MB / 1350 个静态文件。放 `frontend/public/` 会进 git、进 dist，而 `deploy_frontend.py` 是「先 `rm -rf` 远端 dist 再全量上传」，等于每次前端发版白重传 132MB。正解：服务器独立目录 `/var/www/yexingchen/play/pvz/` + nginx alias 直出 + 一次性上传脚本，发布节奏与 dist 解耦。
- **V246144-002 纯静态目录别给 alias 配 try_files**：`location /x/ { alias …; try_files $uri …; }` 里 `$uri` 会按 `root` 而非 alias 解析，容易 404 或回落到 SPA。该目录不需要 SPA fallback，去掉 try_files，缺文件交给默认 404 最干净；入口壳再用 `location = /x/index.html` 单独 `expires -1`（同 `/index.html` 防旧壳残影的理由）。
- **V246144-003 「固定像素布局」的第三方页面，iframe 尺寸必须恒定、缩放交给外层**：PvZ 用 `left:50% + margin-left:-450px` 做居中，iframe 一旦被压窄，内部定位整体错位。做法：iframe 恒 900×600，外层 `transform: scale(容器宽/900)` + `transform-origin:0 0`，用 ResizeObserver 跟随（放大到全屏也自动重算）。
- **V246144-004 移植第三方玩法先核对「方向语义」再抄数值**：RoadRash 原版把「前方」画在屏幕下方（`screen_y = H-150+rel*0.3`），但攻击判定按 `roadPos` 正负 —— 视觉与直觉相反。只搬数值不搬语义，就会出现「前击打后方」的怪手感；统一成「前方在上、前击打前方」后规则文案才自洽。
- **V246144-005 大体积第三方包先本地跑通再上传**：132MB 上传成本高。先用 `python -m http.server` 起本地静态服务 + 浏览器实测（无 JS 报错、能进选关地图、资源全为相对路径）再传，避免白传一次。
- **V246144-006 开源协议要随包保留**：《长江开源协议》要求保持协议副本与署名完整。上传时把 `LICENSE.md` / `LICENSE-CHINESE.md` / `README-CHINESE.md` 一并放进 `/play/pvz/`，站内入口页写明来源与非商业用途。
- **V246144-007 移植别人写的玩法，节奏和结算包络都得重算**：RoadRash 原版 6000 像素路程在当前速度参数下只需 4 秒冲线（作者大概从没跑满过），而且车车相撞是**按帧**扣耐久 —— 被警车贴住 0.3 秒直接归零。搬数值≠搬手感：移植时至少要按「一局多久 / 一次接触掉多少 / 敌方分布合不合理」重新配一遍，本次把路程 ×5、相撞改 20 帧冷却、对手摊到前 40% 路段。
- **V246144-008 「页面上有」≠「用户看得到」，新功能必须挂到用户实际走的入口**：两款游戏第一版只加进了 `GamesView.vue` 的内部列表（娱乐 → 棋类游戏 → 休闲分组），夜星在侧栏「娱乐」分组找不到，直接反馈「我在侧边栏娱乐模块没有看到」。教训：验收口径要按**用户点得到的入口**，而不是「代码里存在 / 页面里渲染了」；凡是"某功能看不到"类反馈，先检查它是否出现在导航注册表（`navModules.js`）这类一级入口里，而不是先怀疑部署。这也是本轮顺手补 `PlayView.vue` + 两条 `/play/*` 路由的由来。

## v2.46.138 手机端标题随滚动 + 去水印接 B 站（2026-10-20）

- **V246138-001 「标题钉住」有两个来源，必须分别拆**：手写子页是 `position: sticky`（`mobile-deink.css` P4 层 + Travels/Stocks 页内断点），island 模块页则是**结构性的**——刊头 `.inner-header` 与滚动容器 `.inner-main` 是兄弟节点，刊头从未参与滚动，删 sticky 无效。**凡是"某一区域滚动时不动"，先分清是 sticky 还是滚动容器归属。**
- **V246138-002 换滚动容器要连带查 JS 监听方**：`CompressToolView` / `PdfToolView` 的底部操作栏用 `closest('.inner-main')` 监听滚动；容器一上移，事件收不到，表现是「按钮凭空消失」而不是报错。**CSS 换容器时，`grep` 一遍 `closest(` / `scrollTop` / `addEventListener('scroll'`。** 保留 `.inner-main` 兜底以兼容桌面。
- **V246138-003 island 外壳的 Tab 栏留白属于"滚动容器"而非"正文"**：72px 底垫原挂在 `.inner-main` 上；容器换成 `.inner-content` 后留白没跟着走，页脚会被固定 Tab 栏盖住。同理任何"贴底留白"都要跟着滚动容器搬家。
- **V246138-004 B 站直链靠 UA 防盗链，Referer 反而无效**：同一 CDN 直链实测 —— 无 UA `403`；只加浏览器 UA `200/206`（Referer 加不加都一样）。所以浏览器侧（预览 / 直链下载）天然可用，**服务端 httpx 必须显式补 UA**，否则"抽音频"这类服务端下载必失败。
- **V246138-005 用户粘的常常不是裸链接**：B 站分享是「【标题】 https://b23.tv/xxx」、可能只给 `BV1xxxxxxxxx`。解析前先归一化（抠第一条 http(s) 链接 → 再认 BV 号补链接），比在下游解析器里加一堆兜底判断干净。
- **V246138-006 排查解析链路先直连下游服务**：本次先在服务器 `curl 127.0.0.1:8070/parse` 打 `parse-service`，确认"解析器本身支持 B 站"，才把精力放到输入归一化与下载 UA 上，避免白改解析器。

## v2.46.129 全站 emoji → 线性图标（2026-10-20）

- **V246129-001 换 emoji 图标只改渲染层，别动数据**：图标值散落在 DB 记录（成员头像 `🌿`）、JS 常量（`AI_AVATARS` / `SKILLS[x].icon` / `GAME_ICON` 映射）里。逐个改数据面太广、还会破坏后端返回与历史存档。做法改成「按 emoji 字符查表画 SVG，查不到回落原字符」——数据零改动，风险收敛在 `AppIcon` 一处。
- **V246129-002 el-select 选中格换不掉图标**：EP 2.7.2 里选中态渲染的是 `label`，必须用 `#label` 插槽接管才换得掉，只改 `option` 里的内容无效。
- **V246129-003 变体选择符要先归一**：`🌤️` = `🌤` + U+FE0F，DB 里可能存带/不带变体符两种写法；查表前统一 `replace(/[\uFE0E\uFE0F]/g,'')`，否则会出现「同一图标一处有画、一处回落成 emoji」。
- **V246129-004 行首 emoji 才是图标，句中 emoji 是标点**：棋牌日志 `log('💀 xx 破产')` 的 emoji 在行首，可提成 `icon` 字段渲染；`msg += ' · 一架归航 🎉'` 这种句尾 emoji 属装饰，直接去掉更干净，硬塞 SVG 会打乱行内排版。
- **V246129-005 大范围并发改文件后必须先整包 build**：本轮由多个子任务并行改了 90+ 文件，`npm run build` 是唯一能一次性暴露 import 路径 / 模板语法 / 取值错误的手段（本轮一次通过）。
- **V246129-006 扫描正则要覆盖全区间，别只扫补充平面**：初版只扫 `U+2600–27BF` + `U+1F300+`，漏掉了 `U+2190–21FF`（`↶ ↷ ↺` 等），导致 `NoteEditorToolbar` 的撤销/重做未被发现。宽范围复扫应含 2190/2300/2460/25A0/2B00 各区间。

## v2.46.143 断链自罚 + 周复盘（2026-10-20）

- **V246144-001 会「自动扣钱」的结算，幂等是第一要求**：`settle` 每次进站都跑，靠
  `HabitPenalty` 的 `(habit_id, miss_date)` 唯一约束 + 代码里的 `paid` 集合双保险，
  否则同一天会被罚两次。**凡是「定时/进站触发的副作用」，先想唯一键，再想逻辑。**
- **V246144-002 「今天」永远不算漏**：结算窗口是 `[start, today)`；今天没过完就不该罚。
- **V246144-003 回溯要设上限**：最多罚 60 天，否则停用半年的习惯进站一次能刷出上百笔流水。
- **V246144-004 完成率的分母要按「这个人从哪天开始」算**：周复盘一开始用
  `items × 本周已过天数`，周三新建的习惯会被算成周一就欠账，完成率永远偏低。
  改成每个习惯按 `max(周一, 创建日)` 单独算天数。
- **V246144-005 罚金要有自己的分类**：塞进「其他」就永远查不出来。加正式分类「断链罚金」，

## v2.46.119 翻页时钟点击入口直接全屏（2026-10-19）

- **V246119-001 flex max-content 循环（Blink）**：flex-column 容器默认 `align-items:stretch` 时，子项宽依赖容器宽；此时给容器 `width:max-content` → 容器尺寸又依赖子项 → **循环定义，Blink 静默回退成填满 containing block**（时钟被拉到旋转平面宽 844px 撑爆视口）。修：容器 `align-items:center` 切断「子项→容器」依赖 + `width:max-content`。诊断手法：对比 `getBoundingClientRect`（旋转后 AABB）与 `offsetWidth`/computed width（未旋转），再 dump 子项 offsetWidth 看谁被拉伸。
- **V246119-002 translate 百分比 ≠ 尺寸一半的坑**：`translate(-50%,-50%)` 的百分比是**元素自身尺寸**，平面尺寸用 vh/vw（100vh×100vw）时其一半是 -50vh/-50vw，写成 translate(-50%,-50%) 值恰好相同——但与 `rotate(90deg)` 组合时**先 rotate 再 translate 的次序**导致平移方向被旋转，元素绕错中心（实测偏出 422px）。修：定位交给 margin（`margin-left:-50vh; margin-top:-50vw`），transform 只留纯 `rotate(90deg)`——默认 origin 50% 50% = 元素中心 = 视口中心，中心不动。
- **V246119-003 vite dev HMR 失效**：编辑组件后 dev server 未感知（编译产物旧），新开页面也拿旧代码——重启 dev server 解决；另注意 SFC 主模块请求不含样式（样式走独立 `?vue&type=style` 请求），grep 主模块判断「代码是否生效」会误判。

## v2.46.44 麻将弃牌布局 + 牌质感（2026-10-11）

- **grid maximize-tracks 陷阱（新坑）**：`minmax(固定min, 固定max)` 的轨道在容器有富余空间时会被撑到 **max**（不是停在内容高度），同容器里的 `1fr` 只吃残羹——上下弃牌行把中间行挤成 0px，左右弃牌格高度归零。隔离实验：`minmax(29.8px, 63.6px) 1fr` 在 147px 容器里算出 `63.6 / 15.8 / 63.6`。要「至多一行」就得**定高**（min==max），别指望 minmax 停在内容高度。

## v2.46.39 掼蛋「挪右侧」语义重定义（2026-10-10）

- **现象**：选中 4 张 9 点「挪右侧」→ 牌甩到整手最末（3 后面）；夜星期望「放在 8 的左边」。
